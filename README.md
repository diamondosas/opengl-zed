# Zed - OpenGL Fork

> **⚠️ This is a custom fork of Zed that uses OpenGL rendering for Linux and macOS instead of the default Vulkan backend.**
> 
> This fork provides support for older GPUs such as Intel HD 4000 and similar integrated graphics that may not support Vulkan. If you need Zed on hardware with limited graphics support, check the [Releases](../../releases) page to download a pre-built version.
